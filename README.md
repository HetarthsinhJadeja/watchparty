# WatchParty 🎬

A real-time synchronized watch party web application that lets people watch videos together remotely.

## 📌 Project Overview

WatchParty aims to make remote movie and video sessions more interactive by allowing users to join a shared room and synchronize playback across multiple browsers.

This project is being developed as a web development project, with a focus on real-time communication, interactive UI, and collaborative experiences.

## ✨ Planned Features

- [ ] Create and join watch rooms
- [ ] Synchronize video playback, including play, pause, and seeking
- [ ] Display room participants
- [ ] Real-time chat and emoji reactions
- [ ] Shareable room links or room codes
- [ ] Handle late joins and playback resynchronization
- [ ] Movie discovery and shared playlists

*Features will be checked off as they are implemented and tested.*

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **UI:** React and Tailwind CSS
- **Real-time communication and backend:** Supabase (planned)

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS version recommended)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/HetarthsinhJadeja/watchparty.git
   cd watchparty
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

> Supabase configuration instructions will be added when backend integration is implemented.
